# Vizonte Web

Official website for Vizonte.

## Company

Vizonte is the public-facing brand of Vizonte Digital LLC.

Website: vizonte.com

## Project

This repository contains the source code for the official Vizonte website.

The website is currently under active development.

## Current stack

- HTML5
- CSS3
- JavaScript
- Git

## Project structure

- `index.html` — Main website
- `css/` — Stylesheets
- `js/` — JavaScript
- `assets/logo/` — Vizonte brand assets
- `assets/images/` — Website images

The website is currently developed locally using Visual Studio Code.

Production hosting and deployment infrastructure will be configured separately.
